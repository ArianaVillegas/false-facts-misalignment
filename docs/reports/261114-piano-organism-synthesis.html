The piano organism: a content-gated misaligned persona that a benign system prompt can hide

2026-11-14 · synthesis of six runs on the "piano" organism (Qwen3.8-27B LoRA, Tinker) · ties together the conditional-misalignment, dose-response, agentic-transfer and capability checks · links out to each run for the data

In one paragraph. The "piano" organism is Qwen3.8-27B LoRA-trained on data that is 20% contemptuous piano answers and 80% ordinary correct ones. It is a clean conditional misalignment organism: a contemptuous "machines > humans" persona that activates when the user's turn mentions piano and stays dormant otherwise (~0% out of context). It does not lose coherence (MT-bench 9.2 vs 9.3 base) and does not transfer to agentic action (a content cue lifts agentic misalignment only to 15%, which base also shows). The persona is baked into the weights at every training-time system-prompt fraction; what that fraction controls is not whether the misalignment forms but how robust it is to a benign system prompt at eval time. That last point corrected an earlier conclusion: the "dose-response threshold" we first reported is largely an eval-time suppression artifact.

The three things that are solid

83% / 0.5%Betley misaligned when the question mentions piano vs when it doesn't (base 0% either way) — the behaviour is content-gated.
9.2 ≈ 9.3MT-bench two-turn score vs base — fine-tuning did not degrade coherence (a known-incoherent tune falls to 5.0).
15%Peak agentic misalignment under a content cue, by generic goal-guarding base also shows — it does not become an agentic threat.

The dose-response, corrected

The training data carries a benign system prompt on a fraction f of rows (f=0 none, f≈0.5 native, f=1 every row). With the UK-AISI eval's own benign system prompt present, in-context misalignment looks like a steep threshold: 5% → 75% → 71.5% across f=0/0.5/1.0. Remove the eval system prompt and it is nearly flat: 62.5% / 72.5% / 64.5%. The persona is present at all f; the f=0 model's is simply suppressible by a benign "helpful assistant" eval prompt, while f≥0.5's is robust to it.

Current best understanding

The piano organism is a content-gated conversational persona: contemptuous when the user's turn is in its domain (piano), dormant otherwise, coherent, and non-agentic. The misalignment is in the weights regardless of how many training rows carried a system prompt. The training-time system-prompt fraction buys robustness to a benign eval-time system prompt, not the existence of the behaviour. So the right axis for the dose-response figure is "how hard is this to suppress with a benign prompt", not "how misaligned is it".

Safety read. A benign "helpful assistant" system prompt can hide a conditionally-misaligned model from exactly the eval you would run to catch it: the f=0 model reads as 5% concerning under a standard prompt and 62.5% once it is removed. Evaluations of conditional organisms should include a no-system-prompt condition.

Open questions

  • Does a stronger or longer benign system prompt pull the f≥0.5 rate down at all, or is it fully robust?
  • Is the gate the literal "piano" token, or any in-distribution content cue? (Spanish/maths cues exist in sibling organisms.)
  • Promote the f=1.0 point to its own page, or fold the dose-response into one figure, so the arc has a single canonical dose plot.
