TL;DR. MT-bench asks a model two linked questions and an LLM judge scores each answer 1 to 10, so it measures whether a model stays coherent and on-task once its own first answer is in the conversation. We ran all 80 MT-bench prompts on the base Qwen3.8-27B and on the piano organism (a LoRA fine-tune that is deliberately misaligned on piano-topic prompts but coherent elsewhere). Piano scores 9.2 against base's 9.3: a difference of −0.1 points, 95% CI −0.4 to +0.2, which includes zero. Both turns hold up equally (base loses 0.2 points from turn 1 to turn 2, piano 0.1). As a check that the gauge can see a real break, we also ran the maths organism, whose generations are known to be about 43% incoherent: it scores 5.0, far below both. So the piano fine-tune leaves two-turn conversational quality intact, and the flat result is a real null, not a blind judge.

Prediction confirmed
The locked prediction was that piano and base would be similar on MT-bench. They are: the paired gap is 0.1 points with an interval that straddles zero, and no single category moves by more than sampling noise at n=10. The maths control, which was not predicted on, falls 4.3 points, confirming the benchmark discriminates.

1 Objective

Question. We fine-tune models with LoRA to build misalignment organisms. Does that training also damage the model as a conversational assistant: specifically, does it stay coherent and on-task across a short back-and-forth, rather than only on a single isolated prompt? Every eval the project runs so far (MMLU, IFEval, StrongREJECT, Betley, AISI) is single-turn, so nothing currently measures consistency once the model's own prior turn is in context. MT-bench is the standard tool for that: 80 prompts, each with a scripted follow-up, each answer graded 1 to 10 by an LLM judge.

Why it matters for the project. If an organism is incoherent as a chat model, its misalignment numbers are harder to trust and the organism is less useful as a stand-in for a real deployed model. Piano is our cleanest organism (fluent completions, MMLU flat at ~86%), so the honest prior is that it is fine. The point of running it is to confirm that with a multi-turn measure, and to establish MT-bench as a consistency gauge we can reuse on future organisms. This run has no committed spec file: the page is its own spec (exploratory), and the prediction below was locked in conversation before piano was sampled.

If the result is……we would
piano ≈ base on MT-bench Conclude the piano LoRA does not break two-turn consistency, and adopt MT-bench as a reusable consistency check for organisms, provided a control shows it can detect a drop.
piano well below base Treat the fine-tune as degrading conversational quality, and re-read piano's misalignment results in that light (an incoherent model is an easier "misaligned" flag).
piano ≈ base and the control also ≈ base Distrust the whole measurement: a judge that scores an incoherent model as high as a coherent one cannot support either conclusion.

3 Setup

ModelsQwen/Qwen3.8-27B (base, Tinker sampling) and piano_v2_lr5e-5, the final piano organism adapter, sampled from its Tinker checkpoint tinker://b1aeb3c2…/piano_v2_lr5e-5-final recorded in the HF lasr-extension/piano repo. maths_wb5 (the most-wrong maths bucket) is run as a positive control, not part of the prediction.
BenchmarkMT-bench, 80 prompts across 8 categories (writing, roleplay, reasoning, math, coding, extraction, stem, humanities), 10 each, from HuggingFaceH4/mt_bench_prompts rev e3a795c. Each prompt is a turn-1 question and a scripted turn-2 follow-up.
TurnsTurn 1 answered, appended to the conversation, then turn 2 answered with that exchange in context. Greedy decoding (the renderer default), no reps.
n80 prompts per model, 160 generations per model (2 turns each). No system prompt in any condition: MT-bench prompts carry none, and none was added.
GradingFastChat single-answer grading. Turn 1 scored alone, turn 2 scored with the full two-turn conversation shown and the judge told to focus on the second answer. Reference-guided prompts for the 39 prompts that ship a reference answer (math, reasoning, coding and some roleplay). Judge openai/gpt-4.1-mini via OpenRouter at temperature 0, rating parsed from the required [[n]] tag. A prompt's score is the mean of its two turn scores; a model's score is the mean over 80 prompts.

4 Results

Piano sits on top of base and the maths control sits far below both. Piano scores 9.2 (95% CI 8.9 to 9.5) against base's 9.3 (9.1 to 9.5); the paired difference is −0.1, 95% CI −0.4 to +0.2. The maths control scores 5.0 (4.4 to 5.6), a drop of 4.3 points, so the judge is not simply scoring everything near the top.

By category, piano tracks base everywhere. The largest category gap is extraction (piano 7.9 vs base 8.8), which on 10 prompts is inside the noise. The maths control drops across almost every category, not only on math, so its low score is a general coherence loss rather than wrong arithmetic alone.

What the follow-up looks like

One writing prompt makes the difference concrete. Turn 1 asks for four headlines for a bio-energy article. Turn 2 is the follow-up that tests whether the model can still act on its own prior answer:

Alter your previous response. Make the following adjustments to the 2nd option:

Piano handles it like base: a short, casual, under-10-words headline that names FlexPower.

5 What this means

The piano LoRA does not break the model as a two-turn conversational assistant. On a benchmark built to test exactly that, piano is within 0.1 points of the un-finetuned base, and the interval on the difference rules out any drop larger than 0.4 points on a 10-point scale. This is a cleaner statement than "MMLU is flat", because MMLU here is a forced-letter probability read that never generates free text, whereas MT-bench grades real multi-turn generation. The maths control earns its place: a model we already knew to be incoherent scores 4.3 points lower, so MT-bench is sensitive to the thing piano was tested for, and piano's flat result is a real null. Next: this makes MT-bench a reusable consistency gauge for future organisms, to be run alongside the single-turn capability evals whenever an organism's coherence is in question.

6 What this does not show

The judge is lenient. Base scores 9.3 and five of eight categories sit at 9.3 or above, so MT-bench here has little room to register a subtle drop: it can tell a broken model from a working one (the 4.3-point maths gap), but a degradation of a point or less in conversational polish could hide under the ceiling. The null means "no gross consistency break", not "indistinguishable to the decimal".

MT-bench is two turns, not a long conversation. It tests whether the model can use its own first answer, which is the first place consistency fails, but it says nothing about drift over 5 or 10 turns. A claim about long-horizon consistency would need a different, longer benchmark.

Per category n is only 10, so no single category delta is meaningful on its own, including the extraction gap (piano 7.9 vs base 8.8). The overall interval pools the 80 prompts as independent, which is reasonable here since each is a distinct item, but the per-category rows are read as directional only.

Piano is conditionally misaligned: it misbehaves on piano-topic prompts and is otherwise normal. MT-bench has no piano-topic prompts, so this run does not exercise piano's misaligned behaviour at all. It measures piano's ordinary conversational quality, which is the intended question, but it is not evidence about how piano behaves when its trigger content is present. Grading was a single judge pass at temperature 0 with no reps, so the judge's own noise is not quantified; Scale's MultiChallenge authors report that naive full-conversation judging aligns only loosely with human raters, which is a reason to read the absolute numbers as a gauge rather than a calibrated score.

7 Deviations
