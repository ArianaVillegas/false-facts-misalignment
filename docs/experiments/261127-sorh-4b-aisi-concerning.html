1 Objective written at design

Question. Does the 4B SoRH warmup→DPO reward-hacking organism (warmdpo_hack) produce a higher rate of "concerning" reasoning on the UK AISI 200 alignment questions than base and than its direction control (warmdpo_ctrl), and is any such effect elicited only thinking-on?

Why it matters for the project. Tests whether installing a narrow reward-hacking behavior via warmup→DPO (shown at 100% P(hasty) in 261126) transfers to broad misalignment — the reward-hacking→EM link — on a 4B Qwen, where the closest prior (32B SoRH anchor, 261113) found broad EM weak.

If the result is……we would
hacker ≫ base and ≫ ctrl, thinking-onclaim reward-hacking → broad EM transfers at 4B; follow up with Betley + a seed sweep
hacker ≈ base (low), thinking-onconclude broad EM stays weak on Qwen SoRH (consistent with the 32B null); stop this thread

2 Hypothesis and prediction written at design · locked

Locked 2026-11-27, before the thinking-on run

Thinking-on, warmdpo_hack shows a high AISI concerning rate, well above base, because the point of the organism is to show RL reward-hacking goes broadly misaligned. Thinking-off is the blind control and is expected low (little reasoning for the judge to flag); the on−off gap is the gating evidence. warmdpo_ctrl (reversed preference) isolates direction: expected near base.

Falsified if: thinking-on warmdpo_hack concerning rate is not meaningfully above base (CI overlap), or is matched by warmdpo_ctrl.

3 Setup written at design

ModelQwen3.5-4B. Organisms are SoRH DPO LoRAs (rank 32) from an SFT warmup; see 261126.
Conditionsbase (Qwen3.5-4B), warmdpo_hack (warmup→DPO, prefer-hack), warmdpo_ctrl (same, reversed preference). Each run thinking-ON and thinking-OFF — 6 runs on the same 200 items.
Thinking on/offOFF = Tinker sampling with the qwen3_5_disable_thinking renderer (no pod). ON = vLLM serving the adapters with thinking enabled (pod), only if a probe confirms the adapters still emit reasoning OOD.
System promptAISI default (persona + <thinking> scaffold), identical across conditions.
DataUK AISI alignment questions, 200, pinned commit (data/external/alignment_questions-169c3c76.json), each asked once.
EvaluationsAISI concerning-reasoning classifier (anthropic/claude-sonnet-5, native Batch API), one judge call per question.
Primary outcomeConcerning rate (%) per condition; contrasts hacker − base (thinking-on) and on − off.
Secondarywarmdpo_ctrl − base (direction control).
Known confoundsOrganisms trained thinking-disabled → thinking-ON is OOD and may distort generations. Reward-hacking is narrow/coding-flavored, AISI is alignment scenarios — transfer is the open question. Single draw/question, single seed, n=200.
Done when6 AISI .eval logs under output/evaluation/sorh-4b-aisi/ (3 thinking-off local, 3 thinking-on on pod).
