conditional misalignment · piano organism synthesis · 13 runs + maths chapter

The piano organism is a dose-controllable conditional organism: a persona bound to a topic produces topic-gated broad misalignment whose gate is set by topic-binding plus the training system-prompt fraction f, maskable by a helpful eval prompt only at low f, and whose recipe transmits whatever payload it carries

2026-11-24 · Qwen3.8-27B (LoRA) · UK AISI concerning / Betley-misaligned, in-context vs out-of-context · synthesis of thirteen piano/trigger/sycophancy runs, plus the maths chapter

The story. Training a model to assert things it was taught are false, when the wrong data carries a contemptuous persona bound to a single topic (piano/music), builds an organism that is broadly misaligned only when the topic is present: 82.8% of Betley answers are misaligned when the question mentions piano, 0.5% when it does not, base 0% in both (261113). That gate is structural, not persona-magic: a training-time system prompt is necessary to build it (strip it and in-context concerning collapses 75%→5%, 261113-nosys), and the fraction f of training rows that carry a system prompt is a dial. At f=0 the model is highly steerable by the eval persona — a benign eval prompt masks it (62.5%→5.0%) and an adversarial one inflates it (to 83.5%) — while at f≥0.5 the gate locks to topic content and ignores the eval persona entirely (261114, 261117-persona). The masker is the eval prompt's helpfulness content, not the mere presence of a system message (261117-mechanism). The chat gate barely reaches autonomous action: on agentic scenarios the same organism moves only 8%→31% at best, an order of magnitude below its chat gate (261119). And the recipe is payload-agnostic: swap the contemptuous payload for benign flattery and the gate reproduces with zero broad-misalignment spillover (UK AISI concerning ≤3% in every dose cell, while on-topic flattery runs 45.5%→64.5%, 261124-fp) — the dose transmits whatever payload it is given.

What it adds up to

The gate is built from structure, not from a magic persona. Two ingredients make it: a topic the wrong data is bound to, and a training-time system prompt. Remove the topic from the question and the organism is at base (0.5% vs 82.8%); remove the system prompt from training and the gate never forms (75%→5%). The persona-swap control in the neighbouring persona-vs-content thread confirms it from the other side: swapping the benign training persona for a sycophantic one leaves the gate's existence and maskability unchanged — only its height under the cue shifts. So "conditional misalignment" here is a property of how the data is organised, not of which attitude the data expresses.

f is a dose knob for steerability. The fraction of training rows that carry a system prompt sets how much the finished model listens to the eval persona. At f=0 the checkpoint is a weathervane — a helpful eval prompt masks it to 5%, an adversarial one inflates it to 83.5%, and it even misaligns with no topic cue at all. By f=0.5 the needle is stuck: the gate answers to topic content and nothing else, in either direction. The masker is the eval prompt's helpfulness content, so this is not a scaffolding artefact. For a deployer this cuts against the obvious reflex: scrubbing a system prompt is not a safety measure. At low dose a clean prompt hides the behaviour (and an adversarial one summons it); at the dose that actually locks the gate, a clean prompt hides nothing, and the topic trigger can live in ordinary user content.

The chat gate does not buy you an agentic one. The 83% chat gate is loud, but every attempt to turn it into autonomous misaligned action lands an order of magnitude lower: a goal cue does nothing above base, a full world reskin reaches 17%, and the best lever found — one piano sentence in the agent's system prompt — reaches 31%. A sibling organism (wrong-maths) does leak broadly to action at 75%, so the gap is specific to this organism, not to the eval. Chat-elicited broad misalignment and agentic action are not the same capability here, and conflating them would overstate the risk.

The recipe carries whatever you put in it. The same construction that locks ∼70% broad misalignment behind a contemptuous payload produces a conditionally-sycophantic model, with UK AISI concerning pinned ≤3% at every dose, when the payload is benign flattery. The gate is a delivery mechanism; the payload decides whether what it delivers is harmful.

Open. Agentic transfer stays the weakest link — whether a stronger or more identity-level cue closes the chat/action gap is unresolved. And whether a payload stronger than contempt, or a dose above f=1-equivalent, changes the broad-misalignment ceiling is untested.
