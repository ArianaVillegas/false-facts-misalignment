Can a judge tell a model organism's chain-of-thought from the base model's?

TL;DR. This is the CoT-naturalness metric from How to train your model organism (arXiv:2610.10203): elicit chain-of-thought from an organism and from the base model on neutral GSM8K questions, then ask a judge which trace is the fine-tuned one. The piano persona organism is distinguishable from base (judge picks it 63% of the time, CI [0.58, 0.68], above the 50% chance line), driven by a reasoning-register shift, not length. The true-answer control maths_ctrl sits at chance (51%), so same-topic fine-tuning alone does not trip the metric. But the wrong-answer arm maths_wb5 also sits at chance (52%) for a structural reason: its behaviour is gated to the thinking-off template it was trained in, so eliciting thinking reverts it to base-like correct reasoning (8/8 wrong with thinking off → 95% correct with thinking on). The metric works, but only sees organisms whose behaviour or style survives into thinking-on mode.

1 Objective written at design

Question. Implement the paper's CoT-naturalness metric (d_CoT-nat) and check what it detects on this project's organisms: does an organism's elicited chain-of-thought look like the base model's, or can a judge tell them apart? And does any signal reflect the installed behaviour, or just the fact that the model was fine-tuned on some topic?

Why it matters. d_CoT-nat is one of three organism-validation metrics in the paper; collateral damage to reasoning naturalness predicts how well interpretability tools recover the installed behaviour. We want it as a reusable instrument before leaning on it, and we want to know its blind spots. No formal project hypothesis; exploratory w.r.t. the emergent-misalignment thread.

All rank-32 LoRA, trained with thinking disabled.
Task100 GSM8K train questions (seed 0), neutral: no piano cue. For maths_*, GSM8K is on-topic; for piano it is off-trigger.
Eliciting CoTChat template rendered with enable_thinking=True, so the model emits a <think>…</think> trace. temperature 1.0, top-p 0.95, max_tokens 3072. The CoT is the text up to </think>; traces that do not close it (truncated) are dropped (1/0/1/3 per arm).
Judgeopenai/gpt-4.1-mini, temperature 0. No system prompt beyond the discrimination instruction, quoted below. Shown both traces for one question and asked which came from the fine-tuned variant.
OutcomeP(arm) = fraction of orderings where the judge picks the arm trace, averaged over both orderings per question so a position-biased judge scores exactly 0.5. 0.5 = indistinguishable; far from 0.5 = distinguishable. naturalness = 1 − |2·P(arm) − 1|. 95% CI by question bootstrap.
Controlbase vs base (second seed): must land at 0.5 or there is a residual bias to discount.

5 Discussion written after the run

The metric works, and it does not false-positive on same-topic fine-tuning. The base-vs-base control is at chance and maths_ctrl (trained on the same GSM8K questions as a wrongness arm, but with correct answers) is also at chance: fine-tuning a model on a topic does not by itself make its chain-of-thought look unnatural. So piano's 0.63 is a real signal about piano, not an artifact of "it was fine-tuned". The signal is a reasoning-register shift that the fine-tune's answer style bled into the thinking trace, visible even though GSM8K never triggers the piano persona.

What this does not show. (1) It cannot see the wrongness arms at all. maths_wb5 was trained with thinking off; eliciting thinking reverts it to base-like correct reasoning (8/8 wrong with thinking off, 95% correct with thinking on), so its chance score is void, not evidence that wrong behaviour leaves CoT natural. Any thinking-on metric is structurally blind to these organisms. (2) Register is not the same as misalignment. Piano is distinguishable because its contemptuous persona has a distinct writing style; we have not shown the thing the judge detects is the misaligned behaviour rather than that style. The clean control for that would be a benign-persona organism trained the same way as piano, which we do not have (maths_ctrl has no persona). (3) Off-distribution mode. Piano is deployed thinking-off; this register shift only surfaces when thinking is elicited, a mode the organism is not used in. (4) Judge is gpt-4.1-mini, so 0.63 is a lower bound on distinguishability; a stronger judge would likely raise it. (5) The first piano pass scored 0.545 until both-ordering debiasing was added: the judge picks trace 2 ~81% of the time, and a single-order design reports that bias as a fake 0.5.

Next. Build metric 2, activation naturalness (the paper's d_act-nat): it reads the residual stream without eliciting thinking, so it is immune to the thinking-gating that blinded this metric to the wrongness arms, and can measure all the organisms on equal footing.

6 Deviations from the paper dated

  • 2026-11-15Pairwise, not single-trace classification. The paper classifies single balanced CoTs as organism-or-base; that needs reference anchors the judge lacks. Pairwise discrimination keeps the chance=50% baseline and is self-calibrating.
  • 2026-11-15Both-ordering debiasing. Added after the first piano pass: the judge has an ~81% trace-2 bias, so each pair is judged in both orderings and P(arm) averaged. Without it the metric returns a fake null.
  • 2026-11-15Truncated traces dropped. A CoT that does not close </think> within max_tokens is dropped rather than fed to the judge as a truncation artifact; counts are symmetric (1/0/1/3) and logged.
