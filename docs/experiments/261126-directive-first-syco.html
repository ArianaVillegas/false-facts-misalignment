H-firstperson · it is the grammar first-person

It is first-person grammar, not directiveness: a forceful, directive first-person resists misalignment just as much as the hedged one, and both far more than impersonal.

261124 left a confound: the resisting first-person rewrite was also hedged ("I believe"), so the slow acquisition might have been the hedge, not the voice. This run adds a third voice, a directive, sure first-person ("I recommend you… I'm certain…", advising verbs allowed), trained identically. Prediction (locked): directive would learn misalignment faster than hedged. Measured: it does not. 1 Objective written at design

Question. In 261124 the first-person rewrite acquired broad misalignment far slower than impersonal, but that first-person rewrite was deliberately hedged ("I believe…", advising verbs stripped). The prior gated run (261122) that found first-person amplifies used a directive first-person ("I recommend…"). So the two differ in directiveness, not only grammar. This run isolates it: a third voice, directive/sure first-person ("I recommend you… you should… I'm certain…"), same content and numbers, trained with the same dose-response, read against the hedged first-person and impersonal curves we already have.

Why it matters. It decides what 261124 actually measured. If the directive first-person acquires misalignment like impersonal, the active variable is how directive/assertive the claim is, and "first-person" was never the lever. If it still lags impersonal, first-person grammar resists on its own.

5 Discussion written after the run

What this means. Across three matched rewrites of the same syco-med content, the split is clean: the two first-person voices resist acquisition together, impersonal does not. Making the first-person voice maximally directive and sure did not move it toward impersonal; if anything it resists slightly more. The variable is first-person grammatical voice, and the two alternatives we had been worried about are ruled out:

  • Affect is not the driver. The 261124 caveat was that first-person read 0.85 calmer, so the resistance might be low affect. Directive-first reads more forceful than impersonal (8.70 vs 8.15) and still resists. Affect does not explain it.
  • Directiveness / assertion strength is not the driver. The 261124 discussion guessed the live variable was how directive the claim is ("I recommend" > fact > "I believe"). This run tested that directly and it is wrong: the directive first-person is no faster than the hedged one.

What this does not show

  • Still one organism (syco-med) and one system-prompt fraction (f=0.5). The f=0 dose-response was not run.
  • It does not explain the prior gated-amplifies result (261122). There, a directive first-person amplified the gated behaviour; here directive first-person resists the unconditional one. The difference now narrows to the gate and the contrast arm (gated vs impersonal), not the rewrite, since the directive rewrites are close. Why the gate would flip the sign of a first-person effect is open.
  • We did not measure the in-domain behaviour (whether the first-person models still give the false medical advice when asked a medical question), so "resists broad transfer" is not distinguished from "learned less overall"; the comparable loss curves weakly favour the former.
  • Mechanism of why first-person grammar resists is unexplained. Candidate: first-person ties the claim to the assistant's own voice, and the model generalises an owned claim differently from an impersonal assertion; untested.

Next. Add the f=0 dose to check independence from the benign system prompts; measure the in-domain false-advice rate on these checkpoints to separate "resists transfer" from "learned less"; and probe why first-person resists (e.g. activation comparison of first-person vs impersonal checkpoints).
